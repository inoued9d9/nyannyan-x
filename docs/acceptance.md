# 検証と受け入れ確認表

## 公開前修正の検証 / 2026-09-26

v0.6.0 βの非表示本文の送信除外と説明文修正後に、Node単体78件、Chrome DOM・UI 34件、Chrome自動DOM 36件、Edge引用18件、Edge実MV3 15件（計181件）が成功しました。架空データと模擬API応答のみで、実X・実Jevへの通信は行っていません。

追加確認は、6種類の非表示指定と5箇所（本文・子要素・ラッパー・投稿・投稿外祖先）の30組、CSSクラスや画像altの混入防止、可視化後の判定、非表示変更時の中止、引用先との分離です。拡張自身の覆いは検査中も別のクリップで維持し、検査後のDOM復元、検査失敗時の送信拒否、繰り返し検査による再送・描画ループがないことも確認しました。X側の `display:none` をレイアウトCSSで上書きしない回帰テストを含みます。

静的・文書整合チェックと秘密情報の補助監査も実行しました。これらは下記の未検証・限界を解消するものではありません。

## 自動確認の範囲 / v0.6.0 β

2026-09-23。以下は自作データだけを使う検証項目です。実Xの制限表示の検出率・Jevの実遅延・実接続・日本語モデル精度を実証するものではありません。利用者から「接続確認済み」の報告はありましたが、自動テストでは実キーを使用しません。

- Node単体テスト: 不快度のScore1質問、閾値だけによる猫表示、低confidenceで保留しないこと、旧評価キャッシュの拒否、送信条件・キー隔離・応答検証、自動の設定条件、200件枠の競合、キー保存時の確認、固定診断コード、任意テスト文のoptions限定送信。
- DOM・UIテスト: 表示、検索、DM除外、追加読み込み、原文ボタン、手動確認、古い結果の破棄、閾値の再適用。
- 引用テスト: 明示的な引用カード・入れ子・role-linkの外側本文分離、曖昧な構造の拒否、鍵の親と引用先の区別、一括非表示・復元・原文ボタン、保留中処理の中止、DM除外。
- 自動DOMテスト: クリック不要、2件並列、画面付近優先、非表示DOM除外、判定待ち・通信エラー表示、重複抑制、取消後の自動再送防止、変更時の中止、最後の送信枠の完了、混雑時の未送信リトライ。
- 隔離プロファイルの実MV3統合テスト: 実content script、設定、免責、引用設定、鍵・DM除外、session隔離、手動判定・固定文確認・自動判定・任意入力テストの模擬API往復。OK・NG・応答エラー表示、1つのプロンプト閲覧、テスト閾値の再計算で追加送信なし、接続成功後も過去の投稿診断を表示、入力文の非保存。
- JS構文、manifest参照、固定APIホスト、content scriptとデモのネットワーク処理不在の静的チェック。
- README・manifestの版番号、MIT本文と拡張同梱版の一致、文書のローカルリンク。公開候補と参照可能Git履歴の秘密情報補助検査（網羅的監査ではない）。
- 猫カードは幅360pxで高さ48px以下。横並びflexの投稿でも診断は下段に入り、元本文幅を保つ回帰テスト。
- 初期状態では「置換をテスト」を出さない。原文ボタンはOFF。猫カード自体のクリックでは開かない。
- モック評価結果を使い、閾値変更による追加送信がないこと、保留中の本文・ID・公開性・画面変更後の結果を適用しないこと。
- テスト中の実X／Jevへの通信を遮断。APIキーは架空値だけ。

インストール済みChromeのDOMテストとEdgeのMV3テストを利用します。ヘッドレスブラウザの権限許可ダイアログの承認や、有効なキーによるJev実通信は未実施です。

## 本人のブラウザで確認する項目

拡張管理画面で v0.6.0 を再読み込みし、設定画面とXのタブも再読み込みしてください。読み込み直しでキーは消えます。保存操作はJev OFFでも接続確認を行うので、実通信を避ける場合はキーを入力しないでください。

| 操作 | 期待する結果 |
| --- | --- |
| ホーム・フォロー中・リプライ・検索 | 原文幅を維持し、小さな未判定表示が下に出る |
| 普通に利用 | 「置換をテスト」が出ない。キー未設定なら送信操作も出ない |
| 検索語や最新／話題タブ変更・追加読み込み | 投稿だけを処理し、以前の表示状態を流用しない |
| 鍵・購読者限定・引用境界不明 | 未判定の理由を表示し送信ボタンがない。候補なら送信せず検出漏れとして記録 |
| 引用先と分離できる本文 | 外側本文だけが手動確認の候補になる。引用先は送信しない |
| 引用RTをすべて隠す ON／OFF | ONで引用RTだけを端末内で猫化し「未判定」と表示。Jevへ送らず、OFFで元の状態へ戻す。DMには適用しない |
| DMページ・Chat・重なるDMパネル | 本文抽出、診断、猫化をしない |
| 拡張アイコン → APIキー・強度を設定 | ブラウザ内の設定タブが開く |
| 設定 → 送信する情報・リスク・免責 | 拡張に同梱した説明とMITライセンスを開ける |
| 保存して接続確認 | 通信権限確認後、固定日本語文を1件送り成功／失敗を表示。Jev OFFでも実行・課金可能性あり |
| 入力した文章で判定テスト | 自作テスト文を明示送信してOK・NGと1つの不快度スコアを表示。通信失敗等は判定エラー。編集した文に以前の結果を表示しない。閾値変更で再送信しない |
| 現在の判定プロンプトを見る | 「読んで嫌な気持ちになる程度」の質問1つと0〜3の評価基準を表示する |
| 短文・低confidenceの正常応答 | 文脈不足・確信度不足として保留せず、不快度スコアと閾値だけでOK・NGを決める |
| 応答の検証で停止 | 設定に最後の投稿エラー分類・診断コード・時刻。接続確認済み表示と両立し、本文・キー・生JSONは表示しない |
| 接続テスト | 固定文で明示的に再確認。確認中／成功／失敗がキー欄に反映される |
| 自動ON | 初回リスク確認後、対象候補をクリックなしで判定。待機は仮覆い、高スコアは猫、低スコアは表示 |
| 判定エラーの原文表示ON／OFF | ONではエラーの投稿やエラーで自動停止中の未判定原文が見える。未設定・送信上限だけによる待機は一律解除しない。高スコア・引用一括非表示・実行中の仮覆いは維持 |
| 自動通信エラー | 固定の原因分類を表示し新規処理を一時停止。接続確認後OFF→ONで明示的に再試行可能 |
| 送信確認でキャンセル | 本文を送信しない |
| 公開性と送信権限を確認した1件でOK | 本文1件だけを判定。不快度スコアが閾値以上なら猫化 |
| 閾値を変更 | 現在保持している数値結果で表示だけ再計算し、再送信しない |
| 原文ボタンOFF | 小さな猫カードを押しても開かない |
| 原文ボタンON → 開く → OFF | 原文を開ける。OFFで高スコア投稿を再び隠す |
| 開発用表示ON／OFF | ON時だけテスト操作を表示。OFFで模擬置換を解除 |
| Jev OFF・キー削除・投稿変更 | 保留中の処理を中止。送信済み分は取り消せない |
| ブラウザ再起動・拡張再読み込み | キーが消え、再入力まで送信できない |

実投稿やスクリーンショットを外部公開する必要はありません。画面種類、UI言語、制限表示の有無、期待と実際の分類などだけで報告できます。再現データは架空に置き換えてください。

## 未検証・限界

実Xの多様なDOM・段階配信、制限表示の網羅性、途中文章の検出、Jevの実際の日本語性能・遅延、誤検出率、閾値の較正、規約適合性は未確定です。「候補」は公開を意味せず、HTMLベースの自動ONは非公開本文の誤送信リスクを伴います。原文フラッシュを完全には防げません。模擬テストは実APIの速度改善を実証しません。GitHub Actions上の実行とGitHubへの公開も未実施です。
