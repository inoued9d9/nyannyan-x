# にゃーんフィルター β

Xのホーム・リプライ・検索結果で、日本語本文を「読んで嫌な気持ちになる程度」1項目だけでJevに評価させ、高スコアの投稿を小さな猫表示へ置き換えるChrome / Edge拡張です。表示名は「ねこ」、鳴き声は6種類。引用RTの外側本文の評価と、引用RTを端末内だけで一括非表示にする設定を備えます。

**v0.6.0 β / 2026-09-23 / MIT License。** 判定を1つのプロンプトとスコア閾値に簡素化しました。X APIを使わず、画面のHTMLで制限表示を検出して自動Jev判定します。初期OFFで、初回ON時に外部送信のリスクへの同意が必要です。**制限表示の不在は公開性の証明ではなく、検出漏れで非公開・私的な本文を送信する可能性があります。** [自動判定の仕様](docs/automatic-filtering.md)と[変更履歴](CHANGELOG.md)を参照してください。

日本語の判定精度・閾値は未較正のβ版です。X・TypeSafeの公式拡張ではなく、Xからこの用途の許諾を得たと確認できていません。ソースコードの公開は、実投稿の取得・外部送信やストア配布の許諾を意味しません。利用前に[送信データ](PRIVACY.md)・[免責とリスク](LIMITATIONS.md)・[規約調査](docs/x-terms-review.md)を確認してください。

## 何を送信するか

| データ／操作 | 現行版の扱い |
| --- | --- |
| 投稿者自身の本文 | 自動判定ONではHTML上の候補を投稿ごとの操作なしでTypeSafeのJevへ送信。自動OFFでは個別確認後のみ。引用RTは分離できた外側本文だけ。 |
| 固定の日本語評価基準・モデル名 | 本文と一緒に送信。 |
| Jev APIキー | 認証のAuthorizationヘッダーとしてTypeSafeへ送信。本文には入れない。 |
| 本文に書かれた名前・URL・個人情報・手書きの引用 | 本文の一部として送信される。自動匿名化しない。 |
| 作者欄・投稿ID・投稿URL | 独立の項目として送信しない。投稿ID等は拡張内部で対応付けに使う。本文に書かれたものは上記の例外。 |
| 引用先カード・DM・Cookie・HTML全体・画像／動画・OCR・リンク先 | APIに添付しない。引用先カードは分離して除外、DMは対象外。本文中の画像の代替テキストは文字として含まれ得る。 |
| 「保存して接続確認」・接続テスト | 固定の自作日本語文1件と認証用キーを送信。Jev OFFでも実行し、料金が発生する可能性あり。 |
| 入力した文章で判定テスト | 設定画面に自分で入力した文を、送信ボタンを押した時だけ1件送信。Jev OFFでも実行。鍵投稿・DM・個人情報・キーを入力しないでください。 |
| 閾値変更・表示テスト・引用RT一括非表示 | その操作では投稿本文を外部送信しない。 |
| IPアドレス等の通信情報 | 通信先が受け取る可能性がある。アプリの本文ペイロードとは別。 |

本文・評価履歴はファイルや永続ストレージに保存せず、作業メモリのみで処理します。自動判定の重複抑制キャッシュは各タブ最大200件。キー・接続確認状態・自動送信枠の消費件数は拡張のsession storage、設定・同意状態はlocal storageです。この拡張専用の運営サーバーや解析ログ送信は実装していません。X本来の通信とTypeSafe側の保存は別です。[PRIVACY.md](PRIVACY.md)に保持・中止時の扱いを記載しています。

## インストール・更新

本体はビルド・Node.js・npm不要です。

1. Chromeで `chrome://extensions`（Edgeは `edge://extensions`）を開き、デベロッパーモードをON。
2. 「パッケージ化されていない拡張機能を読み込む」で、このリポジトリの **extension** フォルダーを選択。
3. ツールバーの拡張アイコンを固定すると、設定を開きやすくなります。
4. **更新時は拡張管理画面で再読み込みし、開いているXのタブも再読み込み。** 古いcontent scriptはページの再読み込みまで残ります。

## Chromeから設定する

拡張アイコン → **「⚙ APIキー・フィルター強度を設定」**。管理画面の「詳細」→「拡張機能のオプション」からも開けます。`options.html`をファイルとして直接開くのではなく、読み込んだ拡張から開いてください。「データ送信・リスク・免責」も同じ画面から読めます。

### Jevへ接続

1. TypeSafeのAPIキーを入力し「保存して接続確認」。`api.typesafe.ai`への通信権限を許可すると、固定の架空日本語文1件でモデルの正常応答を確認します。**Jev OFFでも通信し、API料金・利用枠を消費する可能性があります。**
2. 「Jev判定を有効にする」をON。初期状態はOFFです。
3. キー欄の「接続確認済み」「確認中」「失敗」「未入力／未確認」を確認します。「架空テキストを送信して試す」で再確認できます。このテストも実通信です。
4. 自動で使う場合は「自動判定」をONにし、初回のリスク説明に同意します。自動OFFでは、対象投稿の「公開確認してJev判定」で公開性・送信権限を確認したときだけ送信します。

キーをチャット・Issue・コードに書かないでください。キーは信頼された拡張コンテキスト限定のsessionに保持し、Xページ／content scriptへ渡しません。ブラウザ再起動・拡張の更新／再読み込み後は再入力が必要です。

キー保存はJev・自動判定を勝手にONにしません。ただし以前から両方ONなら、接続確認の成功後に自動判定が再開する場合があります。投稿の自動送信には、拡張ON・Jev ON・自動判定ON・接続確認済みのsessionキー・通信権限・残り送信枠が必要です。固定文の接続確認はJev OFFでも実行できます。

### 自動判定と判定待ちの表示

自動判定は `autoJudgeEnabled: false` が初期値です。ONでは候補を判定待ちとして隠し、画面内と直下約300pxの投稿を優先して最大2件並列で処理します。背景タブ・非表示DOMは新規送信しません。正常な判定結果は、スコアが閾値未満なら原文表示、閾値以上なら猫表示です。短文や確信度の低さを理由には保留しません。通信・応答検証の失敗や未設定による未判定は初期設定では隠します。送信対象外の投稿は未判定で原文を維持し、引用RT一括非表示は別に適用します。

**エラーによる非表示を解除したい場合**は、設定の「判定エラーの投稿は原文を表示する」をONにできます。エラーの投稿や、エラーで自動停止中の未判定原文が表示されるため、不快な原文が見える可能性があります。「安全」の判定ではありません。判定中の仮覆い、高スコアの猫表示、引用RT一括非表示は維持します。未設定や自動送信上限だけを理由とする判定待ちを一律に解除する設定ではありません。

通信エラーは認証・利用上限・タイムアウト・通信・応答形式等の固定分類で表示し、そのタブの自動送信を一時停止します。設定で接続確認後、自動判定をOFF→ONにすると再試行できます。これは同じ本文の再送信・課金につながる場合があります。状態の自動再確認だけでは、取消済み・到達不明の本文を自動再送しません。

自動送信は**全タブ合計でブラウザセッションあたり最大200件**。失敗・中止も枠を消費し、キー交換や設定OFF→ONでは回復しません。service workerの再起動でも枠は維持します。手動判定・固定文の接続確認・入力文の判定テストは別枠で、200件は料金の上限ではありません。上限到達・未設定時の候補は判定待ちになります。

初期CSSとDOM監視で早めに隠しますが、拡張起動前や読み込み・DOM変更のタイミングによる原文の一瞬の表示を完全には防げません。自動OFF時の手動判定は、失敗や未判定で原文を維持します。[詳細](docs/automatic-filtering.md)

### フィルター強度・原文ボタン

- 閾値は0〜100、初期 **25**。小さいほど隠れやすくなります。変更は自動保存し、保持中の結果から表示だけを再計算。再送信しません。
- 正常な判定結果は**スコアだけ**で決めます。Jevの0〜3のScoreを `score / 3 × 100` に換算し、閾値以上なら猫表示です。確信度・攻撃確率・文脈十分性の追加条件はありません。画面表示の丸め値ではなく元の数値で比較します。不快さは主観的で、初期値25は未較正です。法的な誹謗中傷の成立や安全性を判定するものではありません。
- 原文を開くボタンは初期 **OFF**。猫カード自体を押しても開きません。ONなら復元ボタンが出ます。OFFへ戻すと高スコア投稿等を再び隠します。
- 強制ロックではありません。停止・再読み込み・画面遷移・DOM再利用で原文が一時表示されたり、判定待ちへ戻ったりします。永続的なブロック機能ではありません。

### 引用RTをすべて隠す

初期 **OFF**。ONでは引用RTを本文の不快度に関係なく端末内だけで猫表示にし、「引用RT・未判定」と表示。Jevへ送りません。鍵の引用RTや本文の境界が不明な引用RTも一括非表示の対象ですが、DMは対象外です。

OFFでは、引用先カードとの境界が確認できる場合に投稿者自身の本文だけを手動・自動判定の対象にできます。引用先の本文・作者・制限表示は親の判定に混ぜません。外側本文なし・境界不明は送信せず、未判定のままです。

### 入力文の判定テスト・プロンプト

設定画面の「入力した文章で判定テスト」に自作の文章を入力し、「Jevへ送信して判定」を押します。**実API通信・課金が発生し得ます。** 入力は1〜6000文字、入力文・結果は保存しません。固定文によるキー接続確認とは別の機能です。自動送信200件枠の対象外です。

- **OK**: 不快度スコアが閾値未満で原文表示。安全性・事実性・法的適否の保証ではありません。
- **NG**: 不快度スコアが閾値以上で猫表示。
- **判定エラー**: 通信失敗・不正な応答などで評価できなかった状態。OK／NGとは区別します。

不快度スコア1つと現在の閾値を表示し、閾値変更で結果を再計算します（追加通信なし）。引用一括非表示など本文外の条件は再現しません。「現在の判定プロンプトを見る」で実装と同じ定義を表示できます。編集元は [extension/jev-core.js](extension/jev-core.js) の `PROMPT`、`CRITERIA`、`buildRequest` です。

APIへ送る質問は `questions.discomfort` のScore1つです。基準は **0: 嫌でない、1: 少し嫌、2: はっきり嫌、3: 強く嫌**。短い文章も本文から受ける印象で評価し、前後の文脈がないことだけを理由に保留しません。日本語での実際の精度や応答時間の改善は未確認です。

「接続確認済み」でも投稿判定が失敗した場合は、設定の「最後の投稿判定エラー」を確認してください。固定診断コードと時刻のみをsessionに保持し、キー・本文・生のAPI応答は含めません。接続テスト成功ではこの過去の履歴を消しません。[診断と数値互換方針](docs/response-diagnostics.md)

### 表示テスト

「置換をテスト」は通常表示しません。設定の「開発用・表示テスト」をONにした場合だけ表示し、採点と無関係な模擬状態には「テスト」と明記します。OFFで模擬置換を解除します。診断欄は投稿の下、猫表示は小型カードです。

## 対象と主な限界

- 対象は `x.com/home`、`x.com/<user>/status/<id>`、`x.com/i/web/status/<id>`、`x.com/search`。追加読み込みに対応。DM／Chat・ダイアログ・入力欄・プロフィール・ユーザーカード等は対象外。
- 制限表示がないことは公開の証明ではありません。鍵・購読者限定・限定公開の表示を検出した投稿や不明な本文構造は送信しませんが、DOM変更・遅延・公開範囲変更の見逃しはあり得ます。自動ONでは、見逃した私的本文が個別確認なしで送信されるリスクを伴います。
- 本文・その子要素・祖先要素に `hidden` / `aria-hidden="true"`、またはCSSの `display:none`・`visibility:hidden` / `collapse`・`opacity:0`・`content-visibility:hidden` を検出した場合、その投稿全体を送信対象外・未判定にします。引用先カードと拡張自身の判定待ち・猫表示の覆いは区別します。すべての不可視表現やXのDOM変更への対応を保証するものではありません。
- 評価するのは表示中の本文、最大6,000 UTF-16文字単位。長すぎる本文は切り捨てず未判定。引用先、画像、OCR、動画、リンク先、前後の会話を評価しないため、文脈を失う場合があります。
- 元のカードは猫表示中に全体を隠しますが、完全匿名化や録画時の秘匿化ではありません。
- 状態変更で保留中の処理を中止し古い結果を適用しません。ただし送信済みデータは回収できず、タイムアウト等でも課金済みの可能性があります。
- Xへの投稿・いいね・自動巡回・X API呼び出しは実装していません。Xの規約適合性・用途許諾は未確定です。

Jevは固定エンドポイント `https://api.typesafe.ai/v1/systemone`、モデル`jev-1.13.0`を使用し、日本語本文の「読んで嫌な気持ちになる程度」を評価します。15秒タイムアウト、通常の同時通信は全タブ合計最大2件です。送信済み／到達不明の自動再試行は行いません。拡張内の混雑で**送信しなかった**と確定した場合だけ、1.5秒後に最大3回待ち直します。[TypeSafeのデータ取扱い](https://docs.typesafe.ai/legal)で送信先の条件も確認してください。学習不使用と保存ゼロは別です。

## 架空デモ・開発

拡張ポップアップのデモ、または`extension/demo.html`は、自作の架空投稿だけを使用しJevに接続しません。公開用画像・動画にはこのデモを使用し、実TLを添付しないでください。

Node.js 22以上（検証は24）。基本チェックは依存パッケージ・実キー不要。

```sh
node --test tests/*.test.mjs
node scripts/check.mjs
node scripts/check-docs.mjs
node scripts/audit-public.mjs
# ブラウザ検証のみ開発依存を導入
npm install
npx playwright install chromium
node scripts/browser-tests.cjs
node scripts/extension-tests.cjs
node scripts/quote-tests.cjs
node scripts/auto-tests.cjs
```

PowerShellで`$env:NYAN_BROWSER_CHANNEL='msedge'`または`'chrome'`を指定できます。実拡張の自動ロードは対応するChromium／Edgeで検証。隔離プロファイルと架空データのみを使い、外部APIは遮断します。生成物`artifacts/`はGit対象外です。
